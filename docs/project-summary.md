# gmymate 진행 상황 정리

마지막 정리일: 2026-08-03

## 1. 로그인 / 계정

- PHP + MySQL(dothome) 기반 회원가입/로그인
- `index.html` = 로그인 전용 화면, `onboarding.html` = 회원가입 + 프로필 입력
- 자동 로그인(로그인 유지) 체크박스, 로그아웃
- 비밀번호는 `password_hash()`로 해시 저장, 로그인 성공 시 세션 재생성(고정 공격 방지)
- **알아둘 것**: 닷홈 서버가 4xx/5xx 응답의 본문을 자체 에러 페이지로 바꿔치기하는 문제가 있어서, 모든 API가 HTTP 상태코드는 항상 200으로 보내고 실제 성공/실패는 응답 본문의 `{ ok, status, error }`로 판단하는 방식으로 만들어져 있음

## 2. 배포

- 파일질라(FTP 클라이언트)로 수동 업로드가 현재 기본 방법
- `deploy/deploy.ps1` — PowerShell 자동 배포 스크립트도 있음(.NET FtpWebRequest 기반, 업로드 후 실제 HTTPS로 파일 크기까지 검증). curl 기반 첫 버전은 원인 불명으로 실패해서 폐기함

## 3. 운동 기록

- 운동 목록 25종(직접 지정) — 등/하체/가슴/어깨/팔/코어/유산소 카테고리
- 세트별 무게·횟수 기록, 빠른 증감 버튼, 완료 체크
- 세트 목록 UI를 박스 중첩 스타일에서 평평한 리스트 스타일로 정리
- 무게/횟수 입력칸 옆에 "무게"/"횟수" 글자 라벨 추가
- 운동 달력(완료한 날 표시)은 처음부터 있던 기능

## 4. 인바디 기록

- 날짜별 몸무게·골격근량·체지방률 입력
- 지표별 꺾은선 그래프(SVG, 라이브러리 없이 직접 구현)

## 5. 음악 탭

- 하단 네비에 "음악" 탭 신설(음반 모양 아이콘)
- **Spotify / Apple Music / YouTube** 3개 서비스를 계정별로 각각 연동(OAuth)
  - Spotify: 검색 + BPM 자동 태깅(Audio Features API), Web Playback SDK로 앱 안에서 재생 (Premium 계정 필요)
  - YouTube: API 키로 검색, Google 로그인하면 "내 유튜브 좋아요" 목록도 가져옴
  - Apple Music: MusicKit JS 연동(운영자가 Apple Developer Program 연 $99 결제 필요)
- 플레이리스트 생성/삭제, 곡 검색 후 추가/삭제
- BPM 프리셋(웜업 90~110 / 중강도 110~130 / 고강도 130+)으로 운동 강도별 추천
- 쇼츠(60초 이하 영상) 검색 결과·좋아요 목록에서 자동 제외
- 곡 제목의 이모지·〔official video〕같은 군더더기 자동 정리
- 플레이리스트 자동 이어재생(곡 끝나면 다음 곡, 3개 플랫폼 전부 이벤트 연결)
- 곡별 볼륨 슬라이더(완전 자동 음량 정규화는 불가능해서, 수동으로 맞춰두면 재생 시 자동 적용되는 방식)

## 6. 기타

- 핀치줌/더블탭줌 비활성화(운동 중 화면 확대/축소 방지)
- 로그인 화면 새 디자인

## 7. 알려진 한계 / 아직 안 한 것

- (완료됨: 운동 기록·설정·인바디 서버 동기화 — `api/sync.php` + `user_data` 테이블로 이미 구현됨)
- "루틴" 카드가 눌러도 실제 운동을 추가해주지 않는 장식용 버튼 상태
- 유튜브 광고는 코드로 없앨 방법이 없음 — 브라우저 자체가 유튜브 프리미엄 계정으로 로그인돼 있어야 광고 없이 나옴
- 진짜 오프라인 음악 재생은 3개 플랫폼 다 정책상 불가능 (온라인 스트리밍만 가능)

## 8. 설정이 아직 안 됐을 수도 있는 것

- `api/config.php` (DB), `api/music/spotify-config.php`, `api/music/youtube-config.php`, `api/music/google-config.php`, `api/music/apple-config.php` — 각각 실제 자격증명 채워야 작동함
