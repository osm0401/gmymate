## 리서치 근거 (검색으로 확인한 사실 + 왜 이 방식을 택했는지)

- 현재 주요 후보 라이브러리는 다음과 같다.

| Chart.js | [4.5.1](https://github.com/chartjs/Chart.js/releases/tag/v4.5.1) | v4에서 기존 `dist/chart.js`가 제거되고 UMD 파일명이 변경됐다. Canvas 내용은 스크린 리더에 자동 노출되지 않는다. |

- 이 기능은 지표당 최대 8점의 단순 선 그래프다. 저장소가 무빌드 바닐라 ES Module 구조이고 이미 네이티브 SVG 렌더러가 있으므로, 범용 라이브러리를 추가하면 기능보다 버전 관리·CDN 장애·공급망·접근성 비용이 더 커진다. **기존 네이티브 SVG를 보강하는 방식을 선택한다.**
- Chart.js를 사용하더라도 v4의 배포 경로와 ESM 변경을 반영해야 하며, 공식 문서상 Canvas에는 별도 ARIA 또는 대체 콘텐츠가 필요하다. 현재 SVG를 유지하면 DOM·CSS 테마와 접근성 설명을 직접 통제할 수 있다. [Chart.js v4 마이그레이션](https://www.chartjs.org/docs/latest/migration/v4-migration.html), [Chart.js 접근성](https://www.chartjs.org/docs/latest/general/accessibility.html)
- InBody 공식 자료는 체성분 이력에서 체중·골격근량·체지방률을 점 그래프로 추적하며 `recent`는 최근 8회, `total`은 전체 이력을 제공한다고 설명한다. 이번 단일 PR은 모바일 기본 화면에 적합한 **최근 8회**만 채택하고 전체 기간 전환은 제외한다. [InBody 결과 해설](https://research.inbody.com/result-sheet-interpretation/), [최근 8회/전체 이력 설명](https://qr.inbody.com/ri/770/adult/en)
- Samsung Health는 체성분을 주·월·연 단위로 비교하고, Withings는 체중·근육·지방 그래프를 세로로 분리해 배치한다. 이번 PR에서는 단위가 다른 골격근량과 체지방률을 이중축 하나로 합치지 않고 별도 카드로 쌓는다. 기간 선택은 후속 기능으로 남긴다. [Samsung Health](https://www.samsung.com/sec/apps/samsung-health/), [Withings App 8.7](https://support.withings.com/hc/en-us/articles/46386970062609-Withings-App-8-7-Release-Note)
- 현재 SVG는 `aria-hidden="true"`이므로 추이 자체가 보조기술에서 사라진다. W3C 권고에 따라 비장식 SVG에는 명시적 역할과 접근 가능한 이름을 제공하고, 기록 목록을 원자료 대안으로 유지한다. [W3C SVG 접근성 규칙](https://www.w3.org/WAI/standards-guidelines/act/rules/7d6734)

## 예상 리스크

- **중복 구현:** 기본 그래프와 동일 작업 커밋 `38aabc2`가 이미 존재한다. 기준 브랜치 및 기존 PR 확인을 첫 번째 병합 게이트로 둔다.
- **기준 브랜치 불일치:** 현재 `main`과 기능 브랜치의 앱 상태가 다를 수 있다. 인바디 기반 기능이 없는 브랜치에 그래프만 이식하지 않는다.
- **역할 규약 충돌:** 변경 대상이 `src/**`이므로 백엔드 Codex가 직접 구현하면 저장소 규약을 위반한다.
- **협업 문서 누락:** `AGENTS.md`가 요구하는 `docs/collab/**`가 현재 체크아웃에 없다. 기능 PR에 새 규약을 추측해 만들지 말고 정식 복구를 병합 전제조건으로 둔다.
- **희소 데이터:** 두 선택 지표의 기록 날짜가 다를 수 있다. 각 지표를 독립적으로 필터링해야 한다.
- **축 왜곡:** 좁은 값 범위가 큰 변화처럼 보일 수 있다. 단위와 최솟값·최댓값을 항상 노출하고 그래프 간 기울기를 직접 비교하도록 유도하지 않는다.
- **시간대 오류:** UTC 기반 날짜 생성·파싱은 일부 지역에서 날짜를 이동시킬 수 있다.
- **접근성 퇴행:** 현재처럼 SVG를 `aria-hidden`으로만 처리하면 추이 정보가 보조기술에서 사라진다.
- **건강정보 노출:** 체성분 데이터는 민감정보다. 새 로그·분석·외부 전송을 추가하지 않고 기존 계정 저장 경계 안에서만 처리한다.
- **동기화 충돌:** 현재 JSON 동기화의 last-write-wins 정책은 이번 PR에서 해결하지 않는다.
