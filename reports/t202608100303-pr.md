## 작업 지시서 요약

# 목표 설정·운동 알림 MVP — 작업 지시서

## 목표

로그인 사용자가 운동 목표를 수정하고, 선택한 요일·시각에 운동하지 않았을 때 알림을 받도록 한다.

두 기능을 한 PR에 넣지 않는다. 아래 순서대로 각각 구현·리뷰·병합한다.

| 순서 | 브랜치 | 기능 | 담당 |
|---|---|---|---|
| PR 1 | `fe/goal-settings-mvp` | 목표 설정·수정 | `[FE]` |
| PR 2 | `fe/workout-reminder-mvp` | 앱 활성 상태 운동 알림 | `[FE]` |

현재 Codex 역할은 `api/**`만 수정할 수 있으므로 직접 구현하지 않고 FE에 넘긴다. `api/**`, DB 스키마, Composer 의존성은 두 PR 모두 변경하지 않는다.

착수 전 다음 조건을 해결한다.

- 현재 작업 트리에 필수 문서인 `docs/collab/roles.md`, `decisions.md`, `backlog.md`, `handoffs.md`가 없다. 다른 브랜치의 오래된 문서를 그대로 복사하지 말고 실제 기준 브랜치에 맞는 버전을 복구한다.
- 현재 브랜치와 `fe/frontend-refactor`의 모듈 구조가 다르므로 배포 기준 브랜치를 확정한다. 아래 파일 경로는 현재 체크아웃의 ES Module 구조를 기준으로 한다.
- 복구된 `roles.md`에서 FE 브랜치·담당 규칙을 재확인한 뒤 백로그에 두 작업을 별도 항목으로 등록한다.

PR 1의 사용자 약속:

- `목표 유형`, `목표 몸무게`, `주간 운동 횟수`를 로그인 후 수정할 수 있다.
- 저장 즉시 요약과 주간 달성률에 반영되고 기존 동기화로 보존된다.

PR 2의 사용자 약속:

- 알림 사용 여부, 시각, 요일을 설정할 수 있다.
- 앱이 열려 있거나 다시 활성화될 때 조건을 확인해 하루 한 번 알린다.
